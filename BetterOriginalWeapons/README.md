## ⚙️ Installation

Place the compiled `.dll` file of this mod into the `BepInEx/plugins` folder within your game directory.  
For more detailed installation steps, please refer to the [main README](../../README.md).

## 🔗 Dependencies

- **BepInEx 5.4.23.5** or later ([Download](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5))
- **.NET Framework 4.7.2** (runtime environment)

## 🎮 Compatibility

- This mod is built for game version **release_1.0.8**. It is compatible with other mods that do not modify original weapon stats.
- If used alongside other mods that alter weapon properties, conflicts may occur. Please use with caution.

# 更好的原版武器 (BetterOriginalWeapons)

本模组对《枪血意大利黑手党2》中的全部原版武器进行了系统性的平衡调整与手感优化，旨在让每一把武器都更具特色和实用价值，同时提升战斗的流畅度和爽快感。

## 🔗 依赖
