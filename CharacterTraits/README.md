This mod introduces a unique trait system for playable characters in *Guns, Gore and Cannoli 2*. Each character now possesses distinct abilities, damage bonuses, resistances, and playstyle-defining perks, adding strategic depth and encouraging diverse approaches to each run.

## ⚙️ Installation

Place the compiled `.dll` file of this mod into the `BepInEx/plugins` folder within your game directory.  
For more detailed installation steps, please refer to the [main README](../../README.md).

## 🔗 Dependencies

- **BepInEx 5.4.23.5** or later ([Download](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5))
- **.NET Framework 4.7.2** (runtime environment)

## 🎮 Compatibility

- This mod is built for game version **release_1.0.8** and modifies character-specific stats and abilities.
- May conflict with other mods that alter player character attributes. Use with caution.

# 角色特质 (CharacterTraits)

本模组为《枪血意大利黑手党2》中的可玩角色引入了独特的特质系统。每位角色现在都拥有专属的能力、伤害加成、抗性和玩法特性，增加了策略深度，并鼓励玩家在不同对局中尝试多样化的风格。
